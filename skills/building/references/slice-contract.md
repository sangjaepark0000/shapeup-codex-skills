# Slice Contract

Use this before starting an integrated slice.

The contract is not a new package. It is the smallest agreement needed to build the current slice safely inside the approved package.

```md
## Slice Contract: [Name]

User flow:
-

Minimum data/state:
-

Not doing in this slice:
-

Success check:
-

Current unknown:
-
```

## Rules

- The slice must be end-to-end and demoable or verifiable.
- Prefer the most unknown scope early.
- Aim for `Wired but Ugly` before polish.
- If the contract conflicts with the package, stop and return to shaping/package.
- Record the contract in `06-build-log.md`.
