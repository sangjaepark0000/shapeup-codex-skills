# Scope Filter

Use this when a candidate starts attracting extra features.

## Default

Start with `No / Parking Lot`. A feature stays in the package only when it is required for the first bet to work inside the appetite.

## Say No When

- It does not appear in the first success scene.
- Desired outcome still works without it.
- It creates a new core object, user role, permission model, privacy rule, or operational flow.
- It forces the appetite to grow.
- It splits the package sentence into two unrelated changes.
- The reason is mostly "while we are here", "easy enough", or "needed later".

## Say Yes When

- Without it, the package cannot be validated.
- It enables the core user action.
- It fits fully inside the current appetite.
- It reduces a structural risk without opening a new product decision.

## Output

Record the decision in the shape or package:

```md
## Not Doing

- [Feature]: out because [reason]. Revisit only if [condition].
```
